# YT Downloader

Простая программа для Windows, чтобы скачивать видео и музыку с YouTube и других сайтов.
Внутри работает [yt-dlp](https://github.com/yt-dlp/yt-dlp). Ничего устанавливать вручную не нужно.

## Что умеет

- **Видео**: выбор качества от 360p до 4K (2160p). Звук лучшего качества, файл склеивается в `mp4`.
  Если для 4K `mp4` не подходит, программа сохранит `mkv`.
- **Музыка**: только звук. Форматы `mp3` (320 kbps), `m4a` или `opus`.
  В файл добавляются обложка и теги (название и исполнитель).
- **Плейлисты**: вставьте ссылку на плейлист, и все его видео скачаются в отдельную папку.
- **Превью**: обложка, название, длительность и список доступных качеств.
- **Очередь**: можно добавить несколько ссылок, они скачиваются по очереди.
- **Прогресс**: проценты, скорость и оставшееся время, кнопка «Отмена».
- **Прокси и сеть**: HTTP или SOCKS5 прокси с логином и паролем, кнопка «Проверить прокси», настройка таймаута и числа повторов.
  Подробности — в разделе [«Прокси»](#прокси) ниже.
- **Автообновления**:
  - при запуске программа сама скачивает свежую версию yt-dlp (без неё сайты часто ломаются);
  - кнопка «Проверить обновления» показывает версию yt-dlp и ищет новую версию самой программы.
- **ffmpeg** ставится сам, отдельно устанавливать его не нужно.
- Настройки (папка, прокси, последний режим и качество) сохраняются в файл `settings.json` рядом с программой.

## Как установить и запустить (для самых начинающих)

1. Откройте страницу [Releases](https://github.com/screpka228/yt-downloader/releases) этого репозитория.
2. В разделе **Assets** нажмите на файл `YTDownloader.exe`, чтобы скачать его.
3. Запустите скачанный файл двойным щелчком.
4. Если Windows SmartScreen покажет «Защитил компьютер», нажмите **Подробнее**, затем **Всё равно выполнить**.
   Программа не подписана цифровой подписью, поэтому Windows так предупреждает.

## Как пользоваться

1. Скопируйте ссылку на видео или плейлист в браузере.
2. В программе нажмите **Вставить из буфера**.
3. Нажмите **Получить форматы**: появятся обложка, название и список качеств.
4. Сверху выберите режим: **Видео** или **Музыка**.
5. Выберите качество (или формат для музыки).
6. При необходимости выберите папку через **Выбрать папку**. По умолчанию это папка «Загрузки».
7. Нажмите **Добавить в очередь**. Чтобы добавить ещё ссылки, повторите шаги 1–7.
8. Следите за прогрессом внизу. Загрузку можно остановить кнопкой **Отмена**.

## Прокси

По умолчанию программа использует **встроенный обход DPI**: она сама запускает локальный прокси
на `127.0.0.1` и при подключении к YouTube разрезает служебный пакет (ClientHello), чтобы провайдерский
DPI не видел название сайта. Внешние серверы и VPN не нужны. Нажмите «Автоподбор метода», и программа
сама выберет рабочий вариант. Внешний HTTP или SOCKS5 прокси можно выбрать, если встроенный не помогает.
Режим «Без прокси» — для проверки.

Пакет обхода — отдельный модуль [dpi-proxy](dpi-proxy/README.md), его можно установить через pip.

**Как настроить:** откройте страницу «Настройки», включите переключатель «Использовать прокси»,
выберите тип (HTTP или SOCKS5), введите адрес, порт и, если есть, логин и пароль.
Нажмите «Проверить прокси». Если появилась зелёная надпись, прокси работает.

**Где взять прокси:**
1. Платные прокси-сервисы. Ищите по запросам «residential proxy» или «datacenter proxy».
   Обычно вы покупаете пакет и получаете адрес, порт, логин и пароль.
2. Свой сервер (VPS) с SOCKS5 или HTTP-прокси, если умеете его настроить.
3. Бесплатные общедоступные прокси не рекомендуем: они часто медленные и нестабильные,
   а через них могут видеть ваши данные.

Пароль от прокси хранится в файле `settings.json` рядом с программой, на вашем компьютере.

## Частые ошибки

| Сообщение | Что делать |
|---|---|
| Нет подключения к интернету | Проверьте интернет или прокси |
| Неверная или не поддерживаемая ссылка | Проверьте, что ссылка полная и начинается с `https://` |
| Видео недоступно | Видео удалено, скрыто или закрыто для вашего региона |
| Видео требует входа в аккаунт | Такие видео программа пока не умеет скачивать |
| Сервер временно ограничил доступ (403/429) | Подождите немного или смените прокси |

## Для разработчиков: сборка и запуск из исходников

Нужен Python 3.10 или новее.

```bash
python -m pip install -r requirements.txt
python main.py
```

Собрать `.exe` можно двойным щелчком по `build.bat` или командой из него.
Готовый файл появится в папке `dist`.

## Структура проекта

| Файл | Что внутри |
|---|---|
| `main.py` | Точка входа: обновление yt-dlp и запуск окна |
| `gui.py` | Окно программы (customtkinter) |
| `downloader.py` | Получение информации и загрузка через yt-dlp, понятные ошибки |
| `deps.py` | Обновления yt-dlp, программы и подготовка ffmpeg |
| `settings.py` | Чтение и сохранение `settings.json` |
| `app_config.py` | Версия программы, адрес репозитория, пути |
| `make_icon.py` | Создание иконки `icon.ico` |
| `build.bat` | Сборка `.exe` через PyInstaller |
